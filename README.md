# 🎮 GAME-ZONE
Welcome to **GameZone**, a fun and interactive gaming website where users can enjoy different games in one place!

This project is developed using **HTML, CSS, and JavaScript** with a modern design and interactive gaming features.

## 🚀 Features

- 🎯 Simple and user-friendly interface
- 🎨 Attractive and responsive UI design
- 🌙 Dark theme design
- ❌⭕ Tic Tac Toe Game
- 🐍 Snake and Ladder Game
- 🏀 Jumping Ball Game
- ⚡ Interactive gameplay using JavaScript
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling, animations, and layout
- **JavaScript** – Game logic and interactivity

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server or your browser.
5. Enjoy playing games!

## 🎯 Project Objective

The main objective of this project is to develop an interactive gaming platform using frontend web technologies and improve practical skills in HTML, CSS, and JavaScript.
